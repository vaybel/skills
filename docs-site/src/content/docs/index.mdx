## Install

<Steps>

1. Add the marketplace and install the plugin in Claude Code:

   ```text
   /plugin marketplace add vaybel/skills
   /plugin install vaybel@vaybel
   ```

2. Set `VAYBEL_PAT` once in your agent settings, and reuse it for both the
   Vaybel MCP server and these skills. Create a PAT in Vaybel at
   **Dashboard → Settings → MCP** — [create a free account](https://vaybel.com)
   first if you do not have one.

3. Run a workflow:

   ```text
   /vaybel:launch-product "washed trail running poster art on a heavyweight tee"
   ```

</Steps>

Prefer a clone, or installing into Codex or Cursor? See [Install](/skills/start/install/).

## How it works

Vaybel Skills follow the code-execution-with-MCP pattern. A skill is not a pile
of tool calls for the model to sequence — it is a `SKILL.md` that tells the
agent when to run the workflow, plus a TypeScript runner that does the
sequencing, waiting, and error handling deterministically.
